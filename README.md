# Klinik Dora - Modul Farmasi

Aplikasi web sederhana (HTML/CSS/JS) untuk kebutuhan user farmasi klinik dengan modul:

1. Pembelian obat ke supplier
2. Stok opname obat
3. Laporan pembelian obat dengan filter item/periode/supplier
4. Master supplier
5. Laporan penjualan obat dengan filter item/periode
6. Retur obat (ke supplier & dari pasien)
7. Data stok obat realtime

## Cara jalankan

Cukup buka `index.html` di browser.

Data tersimpan di `localStorage` browser dengan key `dora-farmasi-data-v1`.
